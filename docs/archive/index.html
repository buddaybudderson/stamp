    Archive

    Every issue of The Calibration and The Log, by number and date · newest first

    An issued number is never edited. A correction is issued under a new date and the superseded issue stays here. Each entry links its frozen Source — the file whose SHA-256 is printed in the foot of every page of the PDF. Hash that file, not the reading page, which wraps it.

    Only issues are listed here. The Bench is not an issue and is not listed: it is the blog, about what other people ran rather than what we ran. It carries volume numbers from Vol 002 so an issue can be cited by name, but a Bench volume is not an issue number and does not appear in this archive. It lives here. What separates the three is set out in Definitions.

    figures.json — every citable figure with the first sixteen characters of the SHA-256 of the files it was computed from, and the conditions under which it was measured. The run files behind those digests are not published yet, so a reader cannot recompute them; until they are, the registry is a record of what was hashed, not an invitation to re-hash it.
